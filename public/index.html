Setup from source

The installer sets all of this up. These steps are for running from source: Windows power controls work straight away, and the native bridge adds CPU, Radeon, motherboard and fan sensors.

  1. Install Node.js 24+ and the .NET 8 SDK.
  2. From the project folder, publish the sensor bridge:
    dotnet publish native -c Release -o artifacts/bridge
  3. In PowerShell, point the app at the bridge:
    $env:THINKPAD_BRIDGE = "$PWD\artifacts\bridge\ThinkPad.Bridge.exe"
npm start
  4. Open the printed local URL. Run the launcher from an elevated terminal if sensor access or power-policy writes require it.
ThinkPad fan control and measured RPM

For the reviewed mews-se/TPFanCtrl2 service engine, configure its supported EC driver and model settings, then enable the optional adapter:

$env:THINKPAD_TPFC = '1'
npm start

The GUI provides direct levels 1–7, a firmware-return button and measured RPM for available fans. This integration requires the compatible engine; it does not install an EC driver. A 10-second lease and 85°C watchdog request firmware control when needed. Actual restoration depends on a working engine and driver.

For other LHM fan controls, explicitly allowlist their detected sensor IDs in THINKPAD_FAN_ALLOWLIST. A tachometer alone does not guarantee control. Your Ryzen Radeon GPU may share CPU power and cooling; independent Radeon boost is unavailable in this MVP.

If PawnIO access shows error 5, stop this service and use Launch ThinkPad Control as Administrator.cmd. Windows will ask you to approve elevation.
